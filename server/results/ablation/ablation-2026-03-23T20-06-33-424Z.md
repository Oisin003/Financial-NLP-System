## What This Study Is Doing

This study evaluates audit-rule contribution by disabling one rule (or rule group) at a time and comparing output to labeled expectations.

For each variant, it computes:
- Precision: predicted flags that were correct.
- Recall: expected flags that were found.
- F1: balanced score between precision and recall.
- RAG accuracy: correctness of red/amber/green classification only.

- Variants with lower recall/F1 than baseline indicate removed rules were contributing signal.

- This is a controlled audit-rule ablation only; it does not yet evaluate summarization or NER components.
